## AI Usage

This project was developed with the assistance of Google's Gemini AI model. Gemini was primarily used for:

*   Suggesting code snippets during the development of the `src/utils.py` file.
*   Generating initial drafts of some documentation sections.

The maintainers have reviewed the AI-generated code and believe it is consistent with the MIT license. We have made efforts to ensure that the code is of high quality and meets the project's requirements.

If you have any concerns about the AI's role, please feel free to open an issue.
